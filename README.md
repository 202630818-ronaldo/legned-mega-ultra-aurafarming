# legned-mega-ultra-aurafarming
# 🍽️ 오늘 뭐 먹지?

AI가 오늘 먹을 음식을 대신 결정해주는 인터랙티브 음식 추천 서비스입니다.

## 주요 기능

- 랜덤 음식 카테고리 선택
- 이전 카테고리와 겹치지 않는 새로운 카테고리 생성
- 6가지 AI 결정 스타일
- 다수의 음식 후보 분석
- 단계별 후보 탈락 시스템
- TOP 3 자동 결정
- 최종 1위 자동 결정
- AI 추천 이유 표시
- 실시간 분석 로그
- 반응형 디자인
- GitHub Pages 지원

## AI 결정 스타일

### 냉정한 판사

인기도, 만족도, 건강성 등을 종합적으로 비교합니다.

### 친구처럼 추천

재미, 인기도, 편안함 등을 중심으로 판단합니다.

### 부모님처럼 추천

든든함, 편안함, 건강성 등을 중요하게 판단합니다.

### 점쟁이처럼 추천

랜덤성과 음식의 재미 요소를 섞어 결정합니다.

### 극도로 논리적인 AI

여러 평가 요소를 가중치로 계산합니다.

### 아무 생각 없는 랜덤봇

복잡한 분석 없이 랜덤하게 결정합니다.

## 실행 방법

이 프로젝트는 별도의 서버가 필요하지 않습니다.

`index.html`을 브라우저에서 실행하거나 GitHub Pages에 업로드하면 됩니다.

## GitHub Pages

GitHub 저장소 생성 후 프로젝트 파일을 업로드합니다.

Settings → Pages → Deploy from a branch

Branch를 `main`으로 선택하면 됩니다.
